# T Sai Shiva Kumar - Profile Photograph Slot

To display Shiva's profile picture on the portfolio website:
1. Place the portrait photograph file in this directory with the exact filename:
   public/profile.jpg

2. The website will automatically detect and render the image in the brutalist rectangular frame on the Hero screen without requiring code changes.

If profile.jpg is missing or deleted, the website automatically falls back to displaying the clean brutalist [ PROFILE IMAGE ] placeholder without broken image icons.
